# Михаил Борисович — MVP v0.1.1

Локальный голосовой ассистент для Lubuntu. Vosk распознаёт речь, RHVoice озвучивает ответы. OpenAI API, ключи, платные сервисы, Whisper и локальные LLM не используются. Аудиозаписи не сохраняются; временный WAV ответа удаляется при завершении. Интернет нужен только для первоначальной установки и команды проверки подключения.

## Ручной запуск

В терминале пользовательской графической сессии, без sudo:

```bash
cd /home/sergey/mikhail-borisovich
.venv/bin/python diagnose.py
.venv/bin/python main.py
```

После голосового сообщения о готовности скажите «Михаил» или «Михаил Борисович». Дождитесь «Слушаю» и ещё полсекунды, затем произнесите одну команду. После ответа ассистент снова ждёт обращения. После неизвестной команды он говорит «Не понял. Повторите команду.» и даёт ещё одну попытку без обращения. После второй неудачи: «Не понял. Возвращаюсь в режим ожидания.» Если команда не поступила за 12 секунд, ожидание обращения возобновляется. Экран, мышь и клавиатура в этом цикле не нужны. Первоначальный ручной запуск выполняет помощник; автозапуск пока не настроен.

| Команда | Действие |
|---|---|
| который час / сколько времени / время / час | Системное местное время |
| какая дата / какое сегодня число / сегодняшняя дата / дата | Текущая дата |
| громче / сделай громче / прибавь звук; тише / сделай тише / убавь звук | Изменить громкость на 10 процентных пунктов |
| громкость N процентов | От 0 до 100, число произносится словами |
| открой Firefox / открой браузер | Запустить Firefox |
| закрой Firefox / закрой браузер | Послать SIGTERM процессам Firefox текущего пользователя |
| есть интернет / интернет / проверь интернет / есть связь | Проверить возможность TCP подключения к публичным адресам |
| какой заряд / сколько заряда / батарея / заряд | Заряд и состояние батареи из Linux sysfs |
| повтори | Повторить последний содержательный ответ |
| стоп / замолчи / хватит | Отменить ожидание команды |

Во время синтеза, воспроизведения и защитной паузы распознавание отключено. «Стоп», «замолчи» и «хватит» работают в LISTENING и возвращают к ожиданию «Михаил». Перебивание TTS отключено для защиты от собственного голоса. При громкости 0 ответы неслышны; голосовая команда «Михаил», пауза около двух секунд, «громче» восстанавливает звук. Остановка процесса обслуживающим человеком — Ctrl+C.

## Настройки

`config.json`: `voice: "auto"` выбирает русский мужской Mikhail, иначе первый установленный русский мужской голос. Можно указать имя из диагностики. `input_device: null` использует системный микрофон; можно задать номер или уникальную часть названия. `volume_step` — шаг громкости, `command_timeout` — время ожидания. `sample_rate` — 16000 Гц. `tts_cooldown_ms: 500` — пауза после TTS в миллисекундах (допустимо 300–2000; при заметном эхе попробуйте 700). После TTS и перед возобновлением распознавания очередь очищается; старые кадры отбрасываются по времени поступления.

`silence_rms: 100` — порог пропуска тишины (16-битный PCM). При тихой речи уменьшите его, например до 50; если постоянный шум включает распознавание, увеличьте. В тишине Vosk не получает кадры; проверяется энергия каждого блока по 100 мс. Буфер предыдущих 300 мс сохраняет начало обращения. После звука обрабатывается ещё 1,2 секунды. В ожидании используется словарь из двух обращений и неизвестной речи; для команд — ограниченная грамматика. Одна маленькая модель общая для двух распознавателей. Очередь аудио ограничена.

В словаре модели нет цельного слова Firefox: грамматика использует «файр фокс» и «фаер фокс», которые преобразуются в Firefox. Основные варианты — «открой браузер» и «закрой браузер»; обратный порядок тоже поддерживается. После отдельного «открой» или «закрой» на повторной попытке можно сказать только «firefox»/«браузер». Без этого контекста название браузера не выполняет действие. Сопоставление учитывает границы слов, допускает посторонние слова вокруг фразы; «пять firefox» и «открой час» не выполняются. «Процент замолчи» означает STOP, громкость не меняет.

## Диагностика и проверки

```bash
.venv/bin/python diagnose.py --voices
.venv/bin/python diagnose.py --devices
.venv/bin/python diagnose.py
.venv/bin/python main.py --run-seconds 30
.venv/bin/python test_mvp.py
.venv/bin/python test_mvp.py --recognition
```

Диагностика записывает две секунды с микрофона, сообщает уровень сигнала, проверяет аудиовыход, синтезирует и проигрывает фразу RHVoice, загружает модель и проверяет интернет. Отсутствие интернета не мешает работе. Код завершения 1 означает ошибку локального компонента. Последний тест синтезирует команды в WAV и реально распознаёт их Vosk; это не заменяет проверку человеческой речи через микрофон.

Логи: `[WAITING]`, `[WAKE WORD]`, `[LISTENING]`, `[COMMAND]`, `[SPEAKING]`, `[ERROR]`. При отсутствии микрофона или синтеза выводится понятная ошибка без traceback. В песочнице аудиоустройства могут быть скрыты: запускать нужно в обычной пользовательской сессии Lubuntu. PortAudio использует установленную системную библиотеку `libportaudio2`; RHVoice и его русский голос должны быть установлены.

## Установка на подготовленном окружении

Текущая `.venv` уже подготовлена, модель скачана. Для повторения:

```bash
.venv/bin/pip install -r requirements.txt
mkdir -p models
curl -fL https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip -o models/model.zip
unzip models/model.zip -d models
```

Модель [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models) — архив около 45 МБ, лицензия Apache 2.0. Загружается исключительно по локальному пути; автоматических сетевых загрузок во время работы нет. Громкостью управляет `wpctl`, при его отсутствии — `pactl`; воспроизведение через `pw-play`, `paplay` или `aplay`.

## Границы v0.1.1

Это ассистент с фиксированными командами. Диалога с LLM, ChatGPT Voice, автозапуска, systemd, опасных системных действий нет. Закрытие Firefox затрагивает его окна текущего пользователя; браузер может показать диалог о несохранённых данных, его голосовая обработка пока не реализована.

Акустического эхоподавления нет. Защита от TTS основана на отключении распознавания, сбросе распознавателей и аудиобуферов и паузе после воспроизведения. В шуме возможны ошибки распознавания. Фразу-команду нужно произносить после ответа «Слушаю», а не одним непрерывным предложением с обращением. Достоверность времени зависит от системных часов. Проверка интернета не гарантирует доступность всех сайтов и не изменяет VPN.

## Проверки v0.1.1

Автоматические тесты проверяют варианты намерений, отрицательные примеры из живого лога, уточнение браузера, две попытки и аудиоцикл с имитацией эха TTS. Отдельный тест RHVoice → Vosk проверяет распознавание синтезированных фраз без динамиков. Живая проверка человеческой речи в комнате остаётся необходимой.

Результат проверки 12.09.2026: 9 автоматических тестов и все 15 прежних фраз RHVoice → Vosk прошли. Отдельный 30-секундный запуск с настоящим микрофоном и выводом pw-play: команды «есть интернет» и «который час» распознаны и выполнены, после ответов — WAITING; ложных STOP в этом запуске не было. Средний CPU процесса Python — 14,9% одного ядра, пиковая RAM — 233 МиБ, включая загрузку модели. CPU/RAM дочерних RHVoice и плеера в эти цифры не входят. Это короткий функциональный замер, не оценка длительного тихого ожидания.

Для ручной проверки запустите `.venv/bin/python main.py`: после «Слушаю» выдерживайте полсекунды. Проверьте несколько обращений без команды (нет ложного STOP), короткие «час»/«интернет», открытие и закрытие браузера, неизвестную команду с успешной второй попыткой и две неизвестные подряд. Проверьте STOP в LISTENING и отрицательные примеры «пять firefox»/«открой час».
